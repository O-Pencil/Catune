### 视频规范

- [ ] 时长控制在 60–90 秒。
- [ ] H.264 MP4，确保 Windows 浏览器可离线播放。
- [ ] 1080p 或手机原始录屏，不经过聊天软件二次压缩。
- [ ] 开头直接显示已连接或连接过程不超过 5 秒。
- [ ] 角度变化和猫姿态变化必须在同一段录屏中可见。
- [ ] 最后必须恢复坐直，证明状态可逆而非单向触发。
- [ ] 视频提前在断网环境打开一次。

### 截图规范

- [ ] 使用原始 PNG，不使用聊天软件缩略图。
- [ ] 隐藏个人通知、设备序列号、密钥和无关调试浮层。
- [ ] 不裁掉手机状态、模型名、单位或指标标签。
- [ ] SME2 截图不得只截 `ready`，必须保留 backend 与性能指标。
- [ ] 若 Demo 中打开 Monitor，必须能够看出真实数据源，而不只是一个姿态结论；无需向评委介绍该页面。

## 3. 决赛前必须复验，结果决定演讲口径

### SME2 运行时验证

- [ ] App 显示 `hw sme2=true`。
- [ ] App 显示 `lib sme2=true`。
- [ ] App 显示实际 `backend=SME2`，不能只有 `ready`。
- [ ] logcat 或 MNN 原生日志出现 `sme2:1`。
- [ ] 使用固定模型、固定 Prompt、固定 token 上限和温度。
- [ ] 连续运行至少 3 轮，记录 TTFT、Prefill、Decode TPS、Tokens。
- [ ] 截图或表格标明是单轮值还是去除 warmup 后的平均值。
- [ ] 如做加速对比，必须使用同模型、同 Prompt、同参数的非 SME2 对照。

口径：

- 上述运行时条件全部满足：可说“目标手机运行时已选中 SME2 路径”。
- 只有 hw/lib 为 true：只说“目标手机与推理库具备 SME2 支持，运行时加速仍在最终验收”。
- 不得把历史 NEON 88.69 TPS 写成 SME2 成绩。

### 真实硬件终验

- [ ] 小角度左倾保持 3 秒，腰部符号与猫的视觉方向一致。
- [ ] 小角度右倾保持 3 秒，腰部符号与猫的视觉方向一致。
- [ ] 后仰方向检查通过。
- [ ] 刷入含 `BNO_INIT_RETRY` 的最终固件。
- [ ] 单按 RESET 后能够自动恢复 BNO 与 BLE 广播。
- [ ] 连续运行 10 分钟，无 I2C 中断或不可恢复卡死。
- [ ] 完成 3 次冷连接。
- [ ] 异常姿态提醒/震动与恢复闭环通过。
- [ ] 断连后 App 显示离线/降级状态，不崩溃。
- [ ] 姿态解算与最终猫素材已构建进离线候选 APK。

### 离线候选包

- [ ] 不启动 Metro、不执行 `adb reverse` 时可正常打开。
- [ ] 手机断开电脑并进入飞行模式。
- [ ] 连续冷启动 5 次无白屏、无崩溃。
- [ ] Desk、Plant、Settings 三个核心页面可正常切换；Monitor 仅作为 Demo 调试入口可打开。
- [ ] 模型已安装时完成一次端侧中文推理。
- [ ] 模型异常时规则建议仍然显示。
- [ ] 最终 APK 同时备份到手机、电脑和 U 盘。
