## 演讲前快速启动

```bash
open swiss-html-瑞士风版/index.html
```

1. 浏览器打开后按 `→` 翻页,确认 13 页顺序与动效
2. 按 `P` 进入演讲者模式 → 右上角"开启观众屏"
3. 观众屏打开后,演讲稿 / 当前页 / 下一页 / 计时器全部到位
4. 按 `R` 开始排练计时,反复演练调整每页时长
5. 决赛当天排练时长稳定后,关掉观众屏 → 按 `F11` 全屏 → 开始
