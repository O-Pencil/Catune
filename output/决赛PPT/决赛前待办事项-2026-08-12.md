### 2. ESP32-S3 + BNO085 单节点真实闭环

当前状态（2026-08-13）：单节点基础链路已经真实跑通。ESP32-S3 可烧录；Adafruit BNO085 在 GPIO8(SDA) / GPIO9(SCL)、3.3V、100 kHz I2C 下识别为 `0x4A`；串口已观察到约 43 Hz 有效四元数和 BLE Notify。App 真机已成功连接，扫描期间按钮反馈、重复连接清理和断线状态已修复。

已修复的姿态根因：此前把两个绝对欧拉角直接相减，传感器竖直安装时会在 ±180° 附近跳变并产生轴耦合，实测出现腰椎 70–100° 假值。现已改为 `inverse(qBaseline) × qCurrent` 后再取相对 pitch/roll，并加入任意基线、跨 ±180° 和四元数正负等价测试。该修复尚需安装最新 APK 后做真机方向复验。

当前能力口径：一枚传感器只真实测量其固定位置（当前为胸背节点）的刚体朝向。`thorPitch` 为实测；`lumbarRoll` 复用同一节点的侧倾；`neckPitch` 由胸椎运动学推算。因此当前是“一个真实胸背节点 + 两个估计观测点”，不是三枚传感器独立采集。

最小演示目标：只完成一个胸背节点，不在决赛前强行扩成三枚传感器。

验收标准：

- BNO085 可稳定输出四元数，连续运行 10 分钟无 I2C 中断。
- ESP32-S3 按既有 17 字节协议发送 BLE Notify。
- App 可扫描、连接、断开、重连姿态带。

### 2.1 另外两块 GY-BNO08X 的判断

照片中的紫色 `GY-BNO08X` 提供 `VCC/GND/SCL/SDA/ADO/CS/INT/RST/PS1/PS0`，属于 BNO08x 系列候选模块，理论上可继续使用当前 Adafruit BNO08x 驱动，但丝印不能替代芯片与稳定性验收。

- 逐块断电替换测试，只先接 `VCC→3V3`、`GND→GND`、`SCL→GPIO9`、`SDA→GPIO8`；其余引脚初测悬空。
- 固件已改为依次尝试 I2C `0x4A` 和 `0x4B`，串口应打印 `BNO08X_READY address=...`。
- 每块至少验证：能扫描、能启用 Rotation Vector、四元数范数约为 1、连续 10 分钟无复位/卡死。
- 三块 BNO08x 不能直接并到同一条 I2C 总线：常见可选地址只有 `0x4A/0x4B`，第三块会地址冲突。
- 现有一块 TCA9548A，可用单 ESP32-S3 的 GPIO8/9 接 TCA 主 SDA/SCL，再把三块 BNO08x 分别接到通道 0/1/2，从电气上解决同地址冲突；两块面包板的空间足够。
- TCA9548A 路线仍需新增固件的通道选择、三传感器初始化/复位恢复和 node 0/1/2 轮询发送，且会增加 I2C 联调风险。只有先解决所有裸孔模块的可靠焊接/连接后才进入实验，不替换已跑通的单节点决赛 P0。
- 三节点成品的稳健备选仍是三个独立 ESP32-S3 + BNO08x BLE 节点，或单 ESP32-S3 改多片 SPI 独立 CS；App 端也需相应支持多 BLE 设备或单设备多节点聚合。

### 3. 修复 Desk 姿态图的多轴表达

#### 现状与根因

- `DeskScreen` 当前在 `pitch` 和 `lean` 两套图集之间二选一，只显示偏差更大的轴。
- 因此只能表现前后俯仰或左右侧倾，不能同时表现“低头 + 弯腰”或“弯腰 + 侧倾”。
- c7 / t12 / l5 三个点位使用当前单轴帧的手工锚点，复合姿态下会与猫图位置错开。
- 当前 BLE 单节点映射并不是真正三点采集：胸椎 pitch 来自传感器，腰椎 roll 复用同一传感器，颈椎角度由胸椎运动学推算。

#### 决赛前建议方案

不要临时制作完整二维帧图集。保留猫图作为视觉背景，将 c7 / t12 / l5 三点和脊柱曲线改为独立二维运动学叠加层：

- `neckPitch` 单独控制 c7 的前后/上下位移。
- `thorPitch` 控制 t12 与上半身弯曲量。
- `lumbarRoll` 控制三点整体左右偏移，并让 l5 作为相对稳定的根节点。
- 三个输入可同时参与坐标计算，不再由 `postureAxis` 二选一。
- 对每个角度做限幅、低通滤波和基线校准，避免点位跳动。

验收场景：

| 输入 | 预期视觉结果 |
| --- | --- |
| 仅低头 | c7 前下移，t12/l5 基本稳定 |
| 仅弯腰 | t12 前移，c7 随上背自然联动，l5 稳定 |
| 低头 + 弯腰 | c7 与 t12 同时变化，不能只显示其中一个 |
| 左右倾斜 | 三点横向偏移且脊柱曲线连续 |
| 弯腰 + 左倾 | 纵向和横向变化同时存在 |

对外口径：在单节点硬件完成前，应称“三个脊柱观测点/估计点”，不能称“三枚传感器真实采集”。
